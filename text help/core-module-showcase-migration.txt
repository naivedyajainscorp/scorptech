## Architecture Decision

**Out:** Nine fullscreen Bootstrap modals triggered from card buttons.

**In:** A single `#module-showcase` section — a sticky-tab + inline panel system. The Core Suite cards stay as the visual index; their "Explore" buttons now scroll to and activate the right module panel. Every panel delivers: a tinted header strip (icon + title + stats), a 5/7 split (feature list + primary screenshot), and a sub-feature gallery using the existing `s-cm-pic-card` pattern — all with real UI screenshots from your asset library.

## File 3 — `sapphire.js` additions

Add this function to `sapphire.js` and call it from the page's init block (wherever `initCardTiltEffects()` or other inits are called):

```js
/* ══════════════════════════════════════════════════════
   MODULE SHOWCASE — Tab + Panel System
   Replaces all fullscreen core-module modal behaviour.
   ══════════════════════════════════════════════════════ */

export function initModuleShowcase() {
  const tabs      = document.querySelectorAll('.s-showcase-tab');
  const panels    = document.querySelectorAll('.s-showcase-panel');
  const showcase  = document.getElementById('module-showcase');
  const navEl     = document.getElementById('showcaseNav');

  if (!tabs.length || !panels.length) return;

  function activateModule(moduleId) {
    tabs.forEach(t => {
      const isActive = t.dataset.showcaseTarget === moduleId;
      t.classList.toggle('active', isActive);
      t.setAttribute('aria-selected', String(isActive));
    });

    panels.forEach(p => {
      p.classList.toggle('active', p.id === `showcase-${moduleId}`);
    });

    // Scroll active tab into view within the horizontal scroller
    const activeTab = document.querySelector(`.s-showcase-tab[data-showcase-target="${moduleId}"]`);
    activeTab?.scrollIntoView({ block: 'nearest', inline: 'center', behavior: 'smooth' });
  }

  // Tab bar clicks
  tabs.forEach(tab => {
    tab.addEventListener('click', () => activateModule(tab.dataset.showcaseTarget));
  });

  // Card "Explore" buttons → scroll to showcase + activate module
  document.querySelectorAll('[data-showcase-target]').forEach(btn => {
    // Skip tabs themselves (they already have the click handler above)
    if (btn.classList.contains('s-showcase-tab')) return;

    btn.addEventListener('click', () => {
      activateModule(btn.dataset.showcaseTarget);
      const navOffset = navEl ? navEl.offsetHeight : 0;
      const top = showcase.getBoundingClientRect().top + window.scrollY - 64 - navOffset;
      window.scrollTo({ top, behavior: 'smooth' });
    });
  });
}
```

Then in the existing init block (look for the DOMContentLoaded or the page-level init call area):

```js
// existing init calls ...
initModuleShowcase();
```

**Change Summary**

The entire modal system is replaced by a single `#module-showcase` section using a sticky horizontal tab bar and nine animated inline panels. The "Explore" buttons on the `core-modules-grid` cards switch their `data-bs-toggle/target` attributes to `data-showcase-target` — the JS then scrolls to the showcase and activates the correct panel on click. Every panel preserves the exact content from its former modal (lead text, `core-modules-content-label-list`, stat grids, pill rows) while surfacing real UI screenshots via the existing `s-cm-pic-card` component and a new `s-showcase-screen-primary` wrapper that gives the primary screenshot a polished frame with hover-zoom. Nine new `s-showcase-head-*` utility classes handle the per-module tinted header backgrounds using design-system color values. No Bootstrap modal JS is invoked anywhere; no new libraries are introduced. The tab bar is mobile-optimised: labels collapse to icon-only at `<992px` via a single media query rule.
